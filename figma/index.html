Importing into Figma

  • Run html.to.design and paste one frame URL at a time — each becomes its own Figma frame.
  • Set the import width to 390 px. The page is built mobile-first and its phone rules live in @media (max-width:480px) and (max-width:420px), so the width you import at decides which layout you get. The content column caps at 432 px.
  • Import all four at the same width so the frames line up for comparison.

The pages carry the production CSS, which uses absolute positioning in a few places by design (the SAVE 33% disc over the render, the badge on a pack card, the ready-block arrow). Those arrive as positioned layers rather than auto-layout children — that is the real build, not an import artefact.

States and behaviour

  • Pack selection. 6 Pack is selected on load — border #F3A184 with a 3 px rgba(230,67,13,.15) glow. Choosing a pack updates the pack tag, the render, the SAVE 33% disc (12 Pack only) and every price on the page, including the order summary and the ready strip.
  • Countdown. Starts at 15:00 and ticks once per second in three places — top bar, “reserved for” pill and ready block. They always show the same value.
  • Offer popup. Fires 10 s after load, once per visit, never again once claimed. Closes on the X, the scrim or Esc. Claiming applies −25% to every price and leaves the reader exactly where they were: no scrolling, no navigation.
  • Discounted price. Original struck through in grey beside the new figure in green.
  • Authorization hold note. Under Continue, centred. First sentence always visible, the rest behind Read more / Read less (frame 04 shows it open). It replaced the old “By subscribing…” line.
  • Name. The first name from the intake form is echoed in the top bar and the H1, trimmed before the apostrophe so a stored trailing space cannot render as “Sabbir ’s”.
